# Дальний поиск

[Открыть игру](https://starglader.github.io/far-search/)

Страница игры зашифрована AES-256-GCM, ключ выводится из пароля через PBKDF2-SHA-256 (600000 итераций). Пароль в репозитории не хранится. Исторические исходники остаются публичными; это защита опубликованной страницы, а не серверная авторизация.
