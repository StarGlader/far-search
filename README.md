# Поиск — это космос!

[Открыть полную игру](https://starglader.github.io/far-search/?v=1.0.79)

Версия 1.0.79: демонстрационная главная, вход встряхиванием или нажатием Я, полная игра и новые планеты. На iOS датчик включается отдельным нажатием; нажатие Я работает без разрешения.

Сохранена прежняя защита AES-256-GCM / PBKDF2-SHA-256 (600000 итераций). Пароль и незашифрованная страница не публикуются. Это защита тестовой страницы, не серверная авторизация; исторические исходники остаются публичными.
