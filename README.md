# Дальний поиск — прототип 0.4

[Играть](https://starglader.github.io/far-search/)

Пиксельная космическая аркада для телефона и компьютера. Тёмная тема, яркие кристаллы и серые вращающиеся астероиды.

Ведите палец влево и вправо: корабль движется по дуге и кренится. Движение вверх и вниз слегка меняет глубину. На компьютере работают мышь, стрелки и WASD.

Топливо даёт скорость ×1,5 на 3 секунды и двойные очки за кристаллы. Щит на 4 секунды позволяет разбивать астероиды и собирать осколки. Один возможный магнит за перелёт на 6 секунд втягивает близкие кристаллы за 0,2 секунды; дальние сохраняют траекторию. Кристаллы располагаются короткими диагоналями и дугами по 3 и 5, с промежутками между группами.

Каждый запуск получает новый случайный seed, включая расположение боковых астероидов. У каждого перелёта три непрерывные зоны и визуальный выход на орбиту: планета уходит вниз под корабль, облака привязаны к её поверхности.

Лира → Вега → Нова открываются после успешных перелётов. У каждой планеты три медали: орбита, сбор 25/40/55 кристаллов, полный корпус на финише. Медали и рекорды сохраняются на устройстве. Рекорды раздельные по планетам (far-search-records-v4), прогресс — far-search-career-v1.

11 оригинальных процедурных звуков, без сторонних файлов. Сбор кристаллов — мягкий звон с тремя музыкальными вариантами. Звук включается после нажатия «В полёт», настройка отключения сохраняется. Никакого аудио до действия пользователя.

Запуск локально: `python3 -m http.server 8080` в этой папке. Для GitHub Pages: ветка main, корень репозитория.

Настоящей рекламы, общего рейтинга и запуска встряхиванием пока нет. Внешних шрифтов, аналитики, зависимостей и сетевых запросов внутри игры нет. Автоматические проверки подтверждают правила и собираемость групп; ощущение управления на физическом телефоне и желание повторять требуют пользовательского теста.
